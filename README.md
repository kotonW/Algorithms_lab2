# Лабораторная работа №2 — рекурсивные алгоритмы

Приложение на C# с графическим интерфейсом, которое визуализирует два классических
рекурсивных алгоритма:

1. **Ковёр Серпинского** — фрактал, который строится рекурсивным делением квадрата.
2. **Ханойские башни** — перекладывание колец, решаемое рекурсией.

Окно разделено на три части: слева — выбор задачи, по центру — визуализация,
справа — настройки и информация.

## Требования

- .NET SDK 10.0 или новее
- Windows (приложение рассчитано на Windows; на других ОС Avalonia тоже работает, но не проверялось)

## Запуск

```powershell
dotnet run --project src/AlgorithmsLab2.App
```

Сборка и тесты:

```powershell
dotnet build Algorithms_lab2.sln
dotnet test tests/AlgorithmsLab2.Tests
```

Если тесты не запускаются через `dotnet test` (проект использует xunit v3), их можно
запустить напрямую как обычный исполняемый файл:

```powershell
dotnet run --project tests/AlgorithmsLab2.Tests
```

## Возможности

### Ковёр Серпинского

- Глубина рекурсии выбирается ползунком (0–7).
- Отрисовка растровая: рекурсия дробит квадрат, пока часть не станет размером с пиксель.
- Пошаговая отрисовка: видно, как фрактал «растёт» от глубины 0 до выбранной.
- Палитры оформления (6 вариантов) и переключение светлой/тёмной темы.
- Информация: число клеток `8^n`, площадь фрактала `(8/9)^n`, доля вырезанных «дыр»,
  разрешение растра, фактическая доля закрашенных пикселей, время построения,
  фрактальная размерность `log 8 / log 3 ≈ 1,8928`.

### Ханойские башни

- Число колец задаётся ползунком (1–10); стержни и основание при этом не меняют размер,
  ужимаются только сами кольца.
- Общее число ходов `2^n − 1` и число уже сделанных ходов показываются отдельно.
- Проигрывание с настраиваемой задержкой, шаг вперёд и назад, сброс.
- Видно текущий ход (например, «Кольцо 1: B → C») и прогресс в процентах.
- Кнопка «Сравнить рекурсию и стек»: два способа построить последовательность ходов,
  замер времени и проверка совпадения результатов.

### Перебор всех перестановок

- Рекурсивный перебор с возвратом: элемент фиксируется на текущей позиции, хвост
  перебирается рекурсивно; всего `n!` результатов.
- Замеры по методике первой лабораторной: несколько независимых прогонов на каждую точку n,
  время каждого — через `Stopwatch`, в результат идут среднее, минимум и максимум.
- График зависимости времени от n: измерения и теоретическая кривая `c·n!` оранжевым
  пунктиром. Коэффициент подобран методом наименьших квадратов и показан в легенде,
  легенда закреплена в левом верхнем углу и не перекрывает кривые.
- Клик по точке показывает её координаты (`n` и время); при отпускании кнопки подпись
  убирается. График при этом масштабируется колесом и двигается перетаскиванием —
  подпись не мешает панорамированию.
- Графики подстраивают цвета под светлую и тёмную тему: фон, оси, легенда и цвета кривых
  перерисовываются при переключении.
- Максимальное n — до 15, число прогонов на точку настраивается. Замер можно прервать
  кнопкой «Отмена» даже на n = 15: рекурсия периодически проверяет токен.
- Под настройками показывается оценка длительности замера, чтобы было видно, что n = 15 —
  это часы работы.

### Сохранение состояния

Выбранная задача, глубина, палитра, число колец, скорость, настройки замеров и тема
сохраняются в `%APPDATA%\AlgorithmsLab2\settings.json` и восстанавливаются при запуске.

## Как добавить свой алгоритм

Подсистема замеров построена на интерфейсах, поэтому новый алгоритм не требует ни новых
View, ни правок графика:

```csharp
// 1. Чистый алгоритм без знания о UI и замерах.
public sealed class MyAlgorithm : ITimedAlgorithm<int, long>
{
    public string Name => "Мой алгоритм";
    public long Execute(int n) => /* ... */;
}

// 2. Одна регистрация в ServiceConfiguration.
services.AddSingleton<IAlgorithmBenchmark>(sp =>
    new TimedAlgorithmBenchmark<int, long>(new MyAlgorithm(), myMetadata, n => n));
```

Алгоритм сам появится в выпадающем списке раздела «Замеры», и для него можно построить
график зависимости времени от n.

## Структура решения

```
src/
  AlgorithmsLab2.Domain/       математика фрактала, башен и перестановок, без UI
  AlgorithmsLab2.Application/  сценарии: рендеринг, замеры, ограничения, настройки
  AlgorithmsLab2.Rendering/    единственное место, где используется ScottPlot
  AlgorithmsLab2.App/          Avalonia: окно, ViewModel, XAML
tests/
  AlgorithmsLab2.Tests/        109 тестов на домен и приложение
tools/
  AlgorithmsLab2.Preview/      утилита разработчика: рендерит PNG без запуска UI
```

Подробности архитектуры — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Утилита предпросмотра

Позволяет проверить геометрию и цвета без запуска интерфейса:

```powershell
dotnet run --project tools/AlgorithmsLab2.Preview -- artifacts/preview
```

Команда сохранит PNG с фракталами разной глубины и состояниями башен.
